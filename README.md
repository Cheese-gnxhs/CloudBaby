# CloudBaby 小云朵班级常规养成助手

CloudBaby 是一款面向幼儿园小班教师的互动式 AI 教育小工具。它以“小云朵”作为班级共同照顾的宠物，将幼儿园一日生活中的入园、早操、排队、上课、安静、进餐、午睡、收玩具和离园总结等常规环节，转化为可视化、游戏化、正向化的班级管理过程。

项目希望通过“云朵班宠养成”的方式，让孩子们在照顾小云朵的过程中主动养成良好常规，也帮助教师用更温柔、更具体、更有趣的话术进行日常引导。

## 项目理念

小云朵的成长，就是班级的成长。

在幼儿园小班常规管理中，孩子年龄较小，对抽象规则的理解能力有限。相比单纯的口头要求，孩子更容易被具体、可爱、有情感连接的形象吸引。

CloudBaby 将“小云朵”设计为班级共同照顾的宠物。孩子们每一次主动问好、认真排队、安静午睡、积极收拾玩具、勇敢尝试食物，都会让小云朵获得能量、恢复状态、提升等级并解锁装饰。

本工具不是用批评或惩罚管理孩子，而是通过陪伴、鼓励和游戏化反馈，引导幼儿在真实的一日生活场景中逐步形成规则意识。

## 核心功能

### 1. 一日常规场景切换

系统内置多个幼儿园小班常见场景：

- 入园
- 早操
- 排队
- 上课
- 安静
- 进餐
- 午睡
- 收玩具
- 离园总结

教师可以根据当前活动切换场景。不同场景会触发不同的背景、任务提示和情境话术。

例如：

- 在“排队”场景中，系统会围绕“小火车”“车厢”“站好队伍”生成话术。
- 在“收玩具”场景中，系统会围绕“玩具宝宝回家”“小云朵房间变整齐”生成话术。
- 在“午睡”场景中，系统会围绕“小枕头”“甜甜的梦”“安静能量”生成话术。

### 2. 小云朵班宠养成

小云朵会根据班级表现发生变化：

- 表扬会增加累计能量。
- 温柔提醒会影响当天健康值。
- 能量达到一定数值后，小云朵会升级。
- 升级后会解锁永久装饰。
- 已获得装饰会保留在小云朵身边，代表全班长期努力的成果。

等级成长示例：

| 等级 | 累计能量 | 解锁装饰 |
| --- | --- | --- |
| Lv.1 | 10 | 🎀 蝴蝶结 |
| Lv.2 | 30 | 🌸 小花花 |
| Lv.3 | 60 | 👑 小皇冠 |
| Lv.4 | 100 | 🦋 小蝴蝶 |
| Lv.5 | 150 | 🌈 小彩虹 |
| Lv.6 | 210 | 💎 宝石 |
| Lv.7 | 280 | ⭐ 小星星 |
| Lv.8 | 360 | 🕊️ 和平鸽 |
| Lv.9 | 450 | 🎪 小马戏团 |
| Lv.10 | 550 | 🏆 冠军奖杯 |

### 3. AI 情境话术生成器

CloudBaby 内置本地 AI 情境话术生成器，可以根据以下信息自动生成儿童化话术：

- 当前场景
- 当前对象
- 对象类型：个人、小组、全班
- 操作类型：表扬、温柔提醒、集体鼓励

示例：

```text
幼儿3把玩具宝宝送回家啦，小云朵的房间变整齐了。
````

```text
幼儿5，我们把声音藏进小枕头里，让小云朵也做个甜甜的梦吧。
```

```text
苹果组的小朋友像小火车一样排得整整齐齐，小云朵准备出发啦！
```

当前版本的 AI 话术为本地智能生成，不调用外部大模型接口，不需要 API Key，也不需要联网，保证比赛演示时稳定可运行。

### 4. 幼儿、小组和全班管理

系统默认包含 27 名幼儿，并自动分为 6 个小组：

* 苹果组
* 星星组
* 月亮组
* 太阳组
* 彩虹组
* 云朵组

教师可以选择：

* 单个幼儿
* 某个小组
* 全班

然后进行表扬、温柔提醒或集体鼓励。

系统也支持编辑幼儿名单。教师可以在设置面板中按行输入真实幼儿姓名，保存后系统会自动重新生成幼儿列表和小组信息。

### 5. 数据记录与成长反馈

系统会自动记录以下数据：

* 今日表扬次数
* 今日温柔提醒次数
* 今日集体鼓励次数
* 今日健康值
* 今日小明星
* 小组花瓣进度
* 累计能量
* 当前等级
* 已解锁装饰
* 历史表扬记录
* 表扬信箱

数据会保存到浏览器 localStorage 中。刷新网页后，长期成长数据仍然保留。

### 6. 离园总结

在一天结束时，教师可以点击“离园总结”，系统会生成“今日小云朵成长报告”。

总结内容包括：

* 今日云朵状态
* 今日表扬次数
* 今日提醒次数
* 今日健康值
* 今日小明星
* 小组花瓣表现
* 当前等级
* 累计能量
* 距离下一级所需能量
* AI 教师建议

该功能可以帮助教师在离园前进行简单复盘，也适合作为班级展示或家园沟通的辅助材料。

## 使用方法

### 1. 打开网页

直接双击项目中的 `index.html` 文件，即可在浏览器中运行。

本项目为纯前端项目，不需要安装依赖，不需要服务器，不需要登录，也不需要联网。

### 2. 选择场景

在页面中选择当前班级活动场景，例如：

* 入园
* 排队
* 午睡
* 收玩具

切换场景后，小云朵会显示对应的情境提示。

### 3. 选择对象

教师可以选择：

* 全班
* 某个小组
* 某个幼儿

选中后，对象会高亮显示。

### 4. 点击操作

教师可以点击：

* ✅ 表扬
* 🌱 温柔提醒
* ✨ 集体鼓励
* 🔁 换一句话术
* 📊 查看数据
* 📬 表扬信箱
* 🌙 今日重置
* 🧹 全部清空

点击“表扬”后，小云朵会说出表扬语，并增加累计能量。

点击“温柔提醒”后，小云朵会用温和的方式引导幼儿，不会扣除长期能量，也不会降低等级。

点击“集体鼓励”后，系统会生成面向全班的鼓励语。

### 5. 查看成长变化

教师和幼儿可以观察：

* 小云朵表情变化
* 今日健康值变化
* 累计能量变化
* 等级升级动画
* 永久装饰解锁
* 小组花瓣点亮
* 今日小明星变化

### 6. 生成离园总结

在放学前点击“离园总结”，系统会生成今日成长报告，方便教师带领幼儿回顾一天表现。

## 数据重置说明

系统包含两种重置方式。

### 今日重置

只清空当天数据，包括：

* 今日健康值
* 今日表扬次数
* 今日提醒次数
* 今日小明星
* 今日小组花瓣
* 今日日志

不会清空：

* 累计能量
* 当前等级
* 已解锁装饰
* 历史表扬记录

### 全部清空

清空所有数据，恢复到初始状态。

此操作适合重新演示或重新开始使用，系统会进行二次确认，防止误操作。

## 作品亮点

### 1. 场景真实

覆盖幼儿园小班一日生活中的高频常规管理场景，具有较强的实际使用价值。

### 2. 正向激励

用班宠养成替代直接批评，让孩子通过照顾小云朵主动参与常规建设。

### 3. 智能话术

根据不同场景和对象自动生成儿童化表扬语与温柔提醒语，减轻教师临场组织语言的压力。

### 4. 长期成长

小云朵等级、累计能量和永久装饰不会每天清零，孩子可以持续看到努力带来的变化。

### 5. 操作简单

教师只需完成三步：

```text
选择场景 → 选择对象 → 点击表扬或提醒
```

系统会自动完成话术生成、动画反馈、数据记录和成长统计。
